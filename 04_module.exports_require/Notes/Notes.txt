#require :
In Node.js, the require function is used to load modules or files. 
It allows you to include built-in modules, third-party modules, or your own custom files in your project.

1. Loading Core (Built-in) Modules
Node.js has several built-in modules such as fs, path, http, etc. You can require them directly by name.
const fs = require('fs');    // Filesystem module
const path = require('path'); // Path module

2. Loading Third-party Modules (From npm)
To load an external module, such as one installed using npm (e.g., express), you just use the module name. 
First, make sure you install the module via npm install.
• npm install express
const express = require('express');

3. Loading Local Files
For your own local files or modules, use a relative or absolute path.
// Load a file from the same directory
const myModule = require('./myModule');

// Load a file from another directory
const utils = require('../utils/helper');

4. Module Exports
Modules typically export objects, functions, or classes, which can then be required in other files. 
To make this work, you need to use module.exports in the file being required.

Example:

• myModule.js

// Export a function
function greet() {
  console.log("Hello, World!");
}

module.exports = greet;

• main.js

const greet = require('./myModule');
greet();  // Outputs: Hello, World!

5. Requiring JSON Files
You can also use require to load JSON files.
const config = require('./config.json');
console.log(config);

6. ES Module Alternative (ECMAScript Modules)
In newer versions of Node.js (starting from Node 12.x and above with ES modules enabled), you can use import instead of require. 
This is more in line with modern JavaScript (ES6).

• ES Module syntax:
import fs from 'fs';

However, require is still widely used and supported, especially for CommonJS modules.


// Summary
require allows you to import code from other modules.
module.exports allows you to make functions, variables, or objects accessible to other modules.
You can export a single item or multiple items.
Destructuring can help you pick what you need when importing.
