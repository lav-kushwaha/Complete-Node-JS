==============================
🚀 Deployment Guide: DevTinder
==============================

1. SIGN UP & LAUNCH AWS EC2 INSTANCE
------------------------------------
- Sign up on AWS and launch an EC2 instance (Ubuntu).
- Set permissions on your key file:
  chmod 400 devTinder-secret.pem
- Connect to the instance:
  ssh -i "devTinder-secret.pem" ubuntu@ec2-16-171-19-249.eu-north-1.compute.amazonaws.com
- To disconnect:
  exit


2. INSTALL NODE.JS (v20.15.1)
-----------------------------
(Node.js is already installed. If not, use this:)
  curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
  sudo apt install -y nodejs
  node -v   # Should output v20.15.1


3. CLONE THE PROJECT
--------------------
  git clone <your-repo-url>
  cd DevTinder


4. FRONTEND DEPLOYMENT
----------------------

a. Setup in client/
   cd client
   npm install
   npm run build

b. Install & Start Nginx
   sudo apt update
   sudo apt install nginx
   sudo systemctl start nginx
   sudo systemctl enable nginx

c. Copy Build Files
   sudo cp -r dist/* /var/www/html/

d. Enable Port 80 on AWS:
   - Go to AWS EC2 Dashboard → Security Groups
   - Edit Inbound Rules
   - Add Rule:
     - Type: HTTP
     - Port: 80
     - Source: 0.0.0.0/0

e. Access Frontend:
   http://16.171.19.249/


5. BACKEND DEPLOYMENT
---------------------

a. Connect to EC2 again
b. Enable port 3000 in Security Groups
c. Add EC2 public IP to MongoDB Atlas:
   - Network Access → IP Access List

d. Install PM2:
   cd DevTinder/server
   npm install pm2 -g

e. Start backend with PM2:
   pm2 start npm --name "devTinder-backend" -- start

f. PM2 commands:
   pm2 logs
   pm2 list
   pm2 stop devTinder-backend
   pm2 delete devTinder-backend
   pm2 flush


6. CONFIGURE NGINX FOR BACKEND
------------------------------

Edit Nginx config:
  sudo nano /etc/nginx/sites-available/default

Add the following:

server {
    listen 80;
    server_name 16.171.19.249;

    location / {
        root /var/www/html;
        index index.html index.htm;
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://localhost:3000/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

Restart Nginx:
  sudo systemctl restart nginx


7. UPDATE FRONTEND BASE_URL
---------------------------
Set API base URL in frontend to:
  "/api"


8. DOMAIN SETUP (Optional)
--------------------------
- Map your domain (e.g., devtinder.com) to EC2 public IP: 16.171.19.249
- Add A Record in your domain provider's DNS settings

Result:
- Frontend: http://devtinder.com
- Backend:  http://devtinder.com/api
