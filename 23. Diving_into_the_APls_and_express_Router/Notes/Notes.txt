#express.json()
=>We use express.json() middleware in an Express application to parse incoming JSON payloads.
=>Its read the JSON object from postman or client side and convert into js object.
=>express.json() uses the body-parser package internally.
It:
1.Reads the raw JSON payload from the request.
2.Parses it into a JavaScript object.
3.Attaches it to req.body.

#cookie-parser()
#What is cookie-parser?
=>cookie-parser is a middleware for Express that parses cookies attached to client requests and makes them easily accessible via req.cookies.
=>It helps in both reading cookies sent from the client and optionally signing cookies to ensure integrity.

#express.Router()
- express.Router() is a feature of the Express.js framework that helps in organizing your application’s routing. 
- It creates a mini router instance, which you can use to define routes and middleware separately from the main app. 
- This makes your code modular and easier to maintain.

#Key Uses of express.Router():

1.Modular Routing: Organize routes by separating them into different files or modules.

const express = require('express');
const router = express.Router();

router.get('/example', (req, res) => {
    res.send('Hello from the router!');
});

module.exports = router;

2.Middleware Usage: Attach specific middleware to certain routes or groups of routes.

router.use((req, res, next) => {
    console.log('Middleware for this router');
    next();
});

3.Grouped Routes: Group routes logically, like for different API versions or resources.

const userRouter = require('./routes/user');
const adminRouter = require('./routes/admin');

app.use('/users', userRouter); // All routes for users
app.use('/admin', adminRouter); // All routes for admin

#Benefits:
- Separation of Concerns: Keeps the main application file clean.
- Reusability: Makes routes reusable across different parts of the app.
- Scalability: Helps in scaling the codebase by grouping related routes together.
